## Activity contract

- Eighteen lesson-linked activities rehearse genuine ideas before the associated higher-order capstone, plus one optional cross-course vocabulary clue grid for junior retrieval in the top-level bank. Closely connected sections share an activity when the same mechanic supports both; no activity exists to satisfy a numerical quota.
- The same records feed the top-level bank for lesson use, revision, fast finishers and source-grounded relief teaching.
- Every activity includes answer-neutral support, useful completion/retry feedback, a printable low-tech option, a stable `year7multimedia:activity:` record and lesson/bank return links.
- Sorting and sequencing interactions require keyboard/touch controls and labelled non-drag alternatives. Saved activity records are **Formative practice only**.
